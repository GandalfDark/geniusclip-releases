# GeniusClip

Save your best game moments: the last minutes of screen and sound are always ready, and a clip is one key away.

**[⬇ Download GeniusClip for Windows](https://github.com/GandalfDark/geniusclip-releases/releases/latest/download/GeniusClip-Setup.exe)** · [Website](https://gandalfdark.github.io) · [Source code](https://github.com/GandalfDark/geniusclip)

## Install

1. Download `GeniusClip-Setup.exe` from the link above (or from the [latest release](../../releases/latest) page).
2. Run it. Windows may show "Windows protected your PC" — click **More info → Run anyway** (the installer isn't code-signed yet).
3. Click **Install**. To save a moment in a game, press **Alt + F8**.

Updates arrive by themselves: the app checks this repository and offers to install a new version. The `GeniusClip-…-update.exe` files in the releases are for the automatic updater — you don't need to download them.

GeniusClip is free and open source ([GPL-3.0](https://github.com/GandalfDark/geniusclip/blob/main/LICENSE)).
