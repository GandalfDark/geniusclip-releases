# GeniusClip

Запись лучших моментов из игр: последние минуты экрана и звука всегда наготове, клип сохраняется одной клавишей.

**[⬇ Скачать GeniusClip для Windows](https://github.com/GandalfDark/geniusclip-releases/releases/latest/download/GeniusClip-Setup.exe)** · [Сайт](https://gandalfdark.github.io)

## Установка

1. Скачайте `GeniusClip-Setup.exe` по ссылке выше (или со страницы [последнего релиза](../../releases/latest)).
2. Запустите его. Windows может показать «Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»** (установщик пока без цифровой подписи).
3. Нажмите «Установить». Чтобы сохранить момент в игре, нажмите **Alt + F8**.

Обновления приходят сами: программа проверяет этот репозиторий и предлагает установить новую версию. Файл `GeniusClip-…-update.exe` в релизах нужен для автообновления — скачивать его вручную не нужно.
