# GeniusClip

Запись лучших моментов из игр: последние минуты экрана и звука всегда наготове, клип сохраняется одной клавишей.

## Установка

1. Открой [последний релиз](../../releases/latest) и скачай файл `GeniusClip_…_x64-setup.exe`.
2. Запусти его. Windows может показать «Windows защитила ваш компьютер» — нажми **«Подробнее» → «Выполнить в любом случае»** (установщик пока без цифровой подписи).

Обновления приходят сами: программа проверяет этот репозиторий и предлагает установить новую версию.
